# سفرنامه | Safarnameh Journeys

وب‌سایت مفهومی یک آژانس گردشگری بوتیک با حال‌وهوای مجله سفر؛ ساخته‌شده با HTML5، CSS3 و JavaScript خالص و بدون نیاز به Build.

## صفحات
- `index.html` — صفحه اصلی و اسلایدر تمام‌عرض مقصدها
- `tours.html` — فهرست تورها با فیلتر زنده مقصد، مدت و حداکثر قیمت
- `tour-detail.html` — معرفی تور، برنامه روزبه‌روز، گالری، نقشه SVG تعاملی و فرم درخواست رزرو
- `destinations.html` — مقصدها و بهترین فصل پیشنهادی
- `about.html` — داستان و ارزش‌های برند
- `blog.html` و `article.html` — مجله و صفحه مقاله
- `contact.html` — فرم تماس
- `404.html` — صفحه خطای اختصاصی

## اجرا
فایل `index.html` را باز کن یا پوشه را با افزونه Live Server در VS Code اجرا کن. تصاویر از Unsplash و فونت‌ها از Google Fonts بارگذاری می‌شوند؛ برای نمایش آن‌ها اتصال اینترنت لازم است.

## GitHub Pages
۱. محتویات این پوشه را در ریشه یک Repository قرار بده.
۲. در Settings → Pages گزینه Deploy from a branch را انتخاب کن.
۳. Branch را `main` و Folder را `/ (root)` بگذار و Save کن.
۴. در صورت استفاده از دامنه واقعی، canonical و Open Graph صفحات را از `safarnameh.example` به دامنه خودت تغییر بده.

## تعاملات دمو
- اسلایدر مقصد با کنترل قبلی/بعدی و نقاط انتخاب
- فیلتر زنده تورها بر اساس مقصد، بازه مدت و حداکثر بودجه، به‌همراه مرتب‌سازی
- انتخاب ایستگاه‌های مسیر در نقشه SVG با ماوس و صفحه‌کلید
- باز و بسته کردن روزهای برنامه سفر
- اعتبارسنجی فرم تماس و درخواست رزرو
- منوی موبایل با بستن از طریق Escape و کلیک بیرون
- Reveal هنگام اسکرول و پشتیبانی از `prefers-reduced-motion`

## پیش‌فرض‌ها و محدودیت‌ها
- نام برند، تصاویر نمونه، تورها، قیمت‌ها، زمان‌بندی‌ها، تعداد مسافران و اطلاعات تماس نمایشی هستند.
- قیمت‌ها نرخ زنده یا پیشنهاد قطعی فروش نیستند؛ پیش از استفاده تجاری باید با اطلاعات معتبر جایگزین شوند.
- فرم‌ها فقط اعتبارسنجی می‌شوند و پیام را به سرور ارسال نمی‌کنند. اتصال به CRM، ایمیل یا API رزرو نیازمند پیاده‌سازی سمت سرور/سرویس فرم است.
- نقشه SVG شماتیک و آموزشی است، نه نقشه جغرافیایی یا مسیریابی دقیق.
- تاریخ بهترین فصل‌ها راهنمای کلی است؛ شرایط آب‌وهوا و رویدادها در هر سال تغییر می‌کنند.
